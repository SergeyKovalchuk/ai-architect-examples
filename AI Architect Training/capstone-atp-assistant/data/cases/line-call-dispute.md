title: Disputing a line call (Hawk-Eye / Electronic Line Calling)
tags: [line call, hawk-eye, challenge, electronic line calling, umpire]
---
A player disputes a line call and asks to challenge. On hard and grass courts using
Electronic Line Calling (ELC / Hawk-Eye Live), the electronic call is final and there
are no player challenges. At events still using player challenges, each player gets a
limited number of incorrect challenges per set (typically three, plus one in a tie-break).
On clay courts the chair umpire descends to inspect the ball mark instead of using
electronic review; the umpire's reading of the mark is final. If the player keeps arguing
after the umpire's decision, the umpire may issue a code violation for unsportsmanlike
conduct, and a supervisor can be called to confirm the procedure was followed.
